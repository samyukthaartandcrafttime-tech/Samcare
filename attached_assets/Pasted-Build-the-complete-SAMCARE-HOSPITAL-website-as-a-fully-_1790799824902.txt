# RAPID ASSIST: INJURY IMAGE

Allow the patient to:

* Upload an injury image.
* Preview the image.
* Start analysis.
* See a scanning animation.
* See progressive analysis stages.
* View visible observations.
* See a care category.
* See a recommended doctor.
* Generate a clinical summary.
* Save the case to LocalStorage.
* Send the case to the appropriate doctor's dashboard.
* Create a nurse/staff notification.
* Update the patient's Care Journey.

Clearly separate:

**WHAT IS VISIBLE**

from

**WHAT REQUIRES CLINICAL CONFIRMATION**

Example:

Affected Area: Hand

Visible Observations:

* Localized swelling
* Visible discoloration
* Superficial wound visible

Preliminary Concern:

**Musculoskeletal injury may require clinical assessment**

Confidence:

**Moderate**

Recommended Next Step:

**Clinical evaluation recommended**

Do not claim that an image definitively proves a fracture, infection, disease, or other diagnosis.
